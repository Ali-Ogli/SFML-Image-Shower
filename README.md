# SFML Image Shower

## Introducing

This simple image viewer can easily show you images using an address of a folder contain pictures with extension (.png, .jpeg, .jpg).

This application is a learning project, it contain nothing new to the table, just me creating software with SFML library.

### Features

It can iterate through images after being loaded

No lagging while loading the images

Using SFML to render the images, which is powerful library being used.

### How to use

With left/right arrows to go left and right, up arrow give you random image.

## Compile the code

This application has been compiled with Visual studio 2022

### Libraries

This code need 

- SFML library
- stb_image.h
